# 🔍 SpendLens

> Free AI tool spend auditor for startups — find where you're overpaying and what to switch.

## 🌐 Live Demo
👉 [spendlens-ashen.vercel.app](https://spendlens-ashen.vercel.app)

## ✨ Features
- Audits 8+ AI tools (OpenAI, Anthropic, etc.)
- Rule-based spend analysis engine
- Shareable audit report URLs
- Email delivery via Resend
- Abuse protection & rate limiting

## 🛠 Tech Stack
- Next.js 14 + TypeScript
- Tailwind CSS
- Supabase
- Anthropic API
- Vercel

## 🚀 Getting Started
1. Clone the repo
2. Run `npm install`
3. Add your `.env.local` file
4. Run `npm run dev`
